# AutoRigger

A modular Maya auto-rigger built in Python for bipedal characters so far :3 

## Installation

1. Place the `autoRigger` folder inside:

```
Documents/maya/scripts/
```

> **Important:** The folder **must** be placed in `maya/scripts`, **not** in a version-specific folder such as `maya/2026/scripts`.

## Running the Tool

Open Maya's Script Editor and run:

from autoRigger.modules.uiModules.UI_launcher import run_autorigger
run_autorigger()


Enjoy pootie! :)
